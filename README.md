# 📘 SAP ABAP – Estudos Práticos

## 📌 Sobre o Projeto

Este repositório contém meus exercícios práticos de aprendizado em **ABAP**, desenvolvidos no ambiente SAP.

Os programas seguem uma evolução progressiva, começando com conceitos básicos e avançando até manipulação de banco de dados (CRUD).

🎯 Objetivo: consolidar fundamentos da linguagem ABAP para atuação profissional com SAP.

---

## 📂 Estrutura dos Programas

### 🔹 ZR6001 – Hello World
- Primeiro programa ABAP
- Uso de `REPORT`
- Comando `WRITE`

---

### 🔹 ZR6002 – Formatação de Saída
- Uso de `/` para quebra de linha
- Posicionamento de texto por coluna

---

### 🔹 ZR6004 – Variáveis e Constantes
- `DATA`
- `CONSTANTS`
- Formatação de data e hora

---

### 🔹 ZR6005 – PARAMETERS
- Entrada de dados pelo usuário
- Formatação de saída personalizada

---

### 🔹 ZR6006 – Calculadora Simples
- `RADIOBUTTON`
- Operações matemáticas
- `TRY...CATCH`
- Tratamento de erro (divisão por zero)

---

### 🔹 ZR6007 – Estruturas e Tabelas Internas
- `TYPES`
- Work Area
- Tabelas internas
- `APPEND`
- `LOOP`
- `READ TABLE`
- `MODIFY`
- `CONCATENATE`

---

### 🔹 ZR6008 – CRUD em Tabela Transparente
- Operações em banco de dados:
  - `INSERT`
  - `UPDATE`
  - `MODIFY`
  - `DELETE`
- Controle de transações:
  - `COMMIT WORK`
  - `ROLLBACK WORK`
- Validação com `SY-SUBRC`

---

## 🛠️ Tecnologias

- Tabelas Transparentes (ZT6001)
